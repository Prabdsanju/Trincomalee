# 🌴 2-Day Family Tour: Nawagattegama ➔ Anuradhapura ➔ Trincomalee (Sri Lanka)
> **නවාගත්තේගම සිට අනුරාධපුරය සහ ත්‍රිකුණාමලය දක්වා දෙදින පවුලේ නිවාඩු චාරිකා වෙබ් යෙදුම**

A modern, responsive, highly dynamic single-page web application built with **HTML5**, **Tailwind CSS**, **Vanilla JavaScript**, and **Leaflet.js** for an unforgettable 2-day family trip in Sri Lanka.

---

## 🌟 Key Features

1. **⏳ Countdown Timer & Confetti:**
   - Real-time countdown to **October 16, 2026 at 04:30 AM (Asia/Colombo)**.
   - Tropical Sri Lankan aesthetic with floating ocean wave animations.
   - Interactive confetti celebration trigger button.

2. **🗺️ Interactive Route Map (Leaflet.js + 100% Free OpenStreetMap):**
   - Connects all 8 stops sequentially with animated polyline:
     1. Nawagattegama (Start Point)
     2. Jaya Sri Maha Bodhi & Ruwanwelisaya, Anuradhapura
     3. Trincomalee Hotel & Lunch
     4. Fort Frederick & Koneswaram Temple (Swami Rock / Lover's Leap)
     5. Uppuveli & Nilaveli Beach (Sunset Walk)
     6. Kanniya Hot Water Springs (7 Ancient Thermal Wells)
     7. Marble Beach (SLAF Bay - Calm & Shallow Waters)
     8. Return journey via Habarana - Dambulla - Kekirawa to Nawagattegama.
   - Top-right Layer Switcher: Standard OpenStreetMap, Humanitarian Terrain, and Esri Satellite Imagery.
   - No API keys or watermarks required!

3. **📋 Full 2-Day Tour Schedule (සම්පූර්ණ කාලසටහන):**
   - Side-by-side / sequential visual timeline with exact time slots, descriptions, and family travel tips.

4. **🔔 Smart Proximity Alerts:**
   - Simulated proximity reminder triggers contextual cultural & safety tips (temple attire, shoe counters, sea currents, thermal well rules) in Sinhala & English.

5. **🍲 Meal Stops & Budget Tracker (LKR):**
   - Track Breakfast, Lunch, Dinner, Snacks, and Fuel/Ticket costs.
   - Live total calculation in Sri Lankan Rupees (LKR) with customizable per-person cost breakdown.

6. **🎒 Family Packing Checklist & Sri Lanka Emergency Hotlines:**
   - 1990 Suwa Seriya Ambulance, 119 Police, 1912 Tourism hotline.

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Prabdsanju/Trincomalee.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Trincomalee
   ```
3. Open `index.html` in any modern web browser or start a lightweight local server:
   ```bash
   # Using Python
   python -m http.server 8080
   ```
   Then visit `http://localhost:8080/`.
